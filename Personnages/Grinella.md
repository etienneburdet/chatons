# Grinella

> Jeune grenouille marchande itinérante, courageuse et débrouillarde, que l'on croise sur les routes entre les villes du monde sauvage.

![Illustration de Grinella](Ressources Wiki/grinella.webp)

## Description

Grinella est une jeune grenouille marchande itinérante, que l'on croise sur les routes entre les villes du monde sauvage. Elle voyage souvent avec d'autres voyageurs pour plus de sécurité. Courageuse malgré sa jeunesse, elle garde la tête froide même dans les situations difficiles.
