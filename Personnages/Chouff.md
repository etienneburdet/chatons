# Chouff

> Bœuf brasseur d'Embrasse, l'un des cinq notables du Conseil Salé.

![Illustration de Chouff](Ressources Wiki/chouff.webp)

## Description

Chouff est un bœuf qui tient la brasserie d' [[Lieux/Le Village Portuaire d'Embrasse|Embrasse]]. Il compte parmi les cinq notables élus du Conseil Salé, qui administre le village portuaire.
