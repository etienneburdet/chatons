# Loup / Imed

> Cochon puissant et redoutable, docker et chef de bande dans le quartier de l'Hameçon.

![Illustration de Loup / Imed](Ressources Wiki/loup-imed.webp)

## Description

Imed se fait appeler Loup. Ce cochon puissant et bien bâti est simple docker le jour. La nuit, il devient un redoutable chef de bande qui sème la terreur dans le quartier de [[Lieux/L'Hameçon|l'Hameçon]].
