# Pincedor

> Crabe marchand de matériaux très sollicité, protégé par une garde privée, que les trois petits cochons ont fréquenté.

## Description

Pincedor est un crabe marchand de matériaux de construction, extrêmement sollicité dans le quartier de [[Lieux/L'Hameçon|l'Hameçon]]. Sa garde privée filtre les accès et rend toute discussion directe difficile.
Il a eu maille à partir avec [[Personnages/Grongron, Grangran et Gringrin|les trois petits cochons]], dont les querelles incessantes l'avaient contraint à faire intervenir ses gardes pour les séparer.
