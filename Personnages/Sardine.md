# Sardine

> Chatte rousse gérante des entrepôts d'Embrasse, ancienne aventurière et membre du Conseil Salé.

![Illustration de Sardine](Ressources Wiki/sardine.webp)

## Description

Sardine est une chatte rousse qui gère les entrepôts du port d' [[Lieux/Le Village Portuaire d'Embrasse|Embrasse]]. Ancienne aventurière autrefois connue sous le nom de « Rouquine », elle siège aujourd'hui au Conseil Salé du village.
