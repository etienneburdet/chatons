# Garde royal

> Garde de base peu courageux, chargé de patrouiller dans la forêt pour y traquer les contrebandiers.

![Illustration de Garde royal](Ressources Wiki/garde-royal.webp)

## Description

Les Gardes Royaux patrouillent dans la [[Lieux/Forêt de Mamie Omelette|forêt]] pour traquer les contrebandiers. Ni très courageux ni très motivés, ils peuvent être convaincus de regarder ailleurs si un Chaton s'y prend bien.
Ils communiquent entre eux par cors de chasse lors des battues.
