# Ptolemnos

> Vieux chat aux épaisses lunettes, propriétaire d'un bazar dans l'Arbrachat.

![Illustration de Ptolemnos](Ressources Wiki/ptolemnos.webp)

## Description

Ptolemnos est un vieux chat au poil soyeux, les yeux perpétuellement dissimulés derrière d'épaisses lunettes. Son commerce, le [[Lieux/Bazar de Ptolemnos|bazar de Ptolemnos]], est ouvert depuis de nombreuses années et passe pour une boutique ordinaire, peu rentable. Piètre marchand de toute évidence, Ptolemnos semble pourtant installé ici depuis trop longtemps pour que ce soit simplement le cas.
