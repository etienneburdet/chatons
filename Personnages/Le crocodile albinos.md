# Le crocodile albinos

> Grand crocodile albinos qui rôde dans les profondeurs des égouts de l'Arbrachat.

## Description

Un grand crocodile albinos qui vit dans les profondeurs des [[Lieux/Les Égouts|égouts]] sous l'Arbrachat. Peu en sait sur lui, sinon qu'il est là.
